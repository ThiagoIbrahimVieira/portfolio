## 👨‍💻 Sobre Mim

Olá! Sou o **Thiago Ibrahim Vieira**, tenho 16 anos e sou estudante do **1º ano do Técnico em Informática (TI) na ETEC de Itapevi**.

Minha jornada com a tecnologia começou em **2018**, quando tive meu primeiro contato direto com o computador. O fascínio inicial rapidamente se transformou em vontade de entender a máquina por dentro: como sistemas operacionais gerenciam processos, como o código compila e como construir ferramentas reais e úteis.

Hoje, projeto e desenvolvo sistemas web modernos e soluções de software com foco em:
- **Engenharia Web de Alta Performance:** Interfaces reativas, ricas e táteis desenvolvidas com React 19, Next.js 16 (App Router), TypeScript estrito e Tailwind CSS v4.
- **Sistemas & IA Local (Local-First):** Execução de modelos de IA offline acelerados por GPU (PyTorch CUDA float16), integração de baixo nível no Windows via Win32 API e zero dependência externa forçada.
- **Processamento de Mídia em Memória:** Pipelines de conversão e streaming de áudio, vídeo e imagens diretamente em buffers RAM (zero disk writes).
- **Governança & Agentes de IA:** Orquestração de sistemas autônomos com foco em qualidade, testes, segurança OWASP e transparência total de código.

---

## 🎯 Princípios de Engenharia

1. **Engenharia Transparente (Estágio Honesto):** Sem métricas infladas ou promessas vazias. Cada projeto documenta seu status real, maturidade, decisões de arquitetura e limitações conhecidas.
2. **Local-First & Privacidade:** O processamento deve pertencer ao usuário sempre que possível. Redução de custos desnecessários com nuvem e zero telemetria invasiva.
3. **IA como Braço, Não Piloto Cego:** Inteligência artificial acelera o desenvolvimento, mas o controle, auditoria de código, segurança e decisões críticas permanecem 100% humanos.
4. **Craft & Street-Tech Aesthetics:** Design brutalista funcional com identidade visual autêntica — tipografia display e mono, contrastes nítidos, texturas físicas e fluidez de 60–120 FPS.

## 💻 Como Rodar o Projeto Localmente

```bash
# 1. Clonar o repositório
git clone https://github.com/ThiagoIbrahimVieira/portfolio.git
cd portfolio

# 2. Instalar dependências
npm install

# 3. Iniciar servidor de desenvolvimento (http://localhost:3000)
npm run dev

# 4. Validar tipos e build de produção
npx tsc --noEmit
npm run build
```
